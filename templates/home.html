What is OnToology?

OnToology automates part of collaborative ontology development. Given a GitHub repository with an ontology file, it generates documentation, diagrams, and validation reports based on common pitfalls.

It supports OWL and RDFS vocabularies in RDF/XML and Turtle serializations.

How it works

  • 1. Enter a GitHub repository.
  • 2. Authorize OnToology.
  • 3. Push changes to your ontology.
  • 4. Review and merge the generated pull request.
